Yellow Wave Music Player (russian version).


Дорогие друзья! Я готов представить вам свой последний проект: музыкальный плеер, написанный мной с использованием таких библиотек как PyQt5 (графический интерфейс/GUI), Mutagen (чтение метаданных аудиофайлов), Pygame (для воспроизведения аудио, а также для контроля переходов). Почему это последний проект? А тут всё просто: руки кривые и мозги не соображают. Чтобы написать этот плеер пришлось напрячь голову, и думать куда и что вставлять. Так что обновлений можете не ждать, писать нормально код не умею.


Библиотеки:
PyQt5 версии 5.15.11 и выше.
Mutagen версии 1.47.0 и выше.
Pygame версии 2.6.1 и выше.

Операционная система: любая, на ваш выбор! Windows, MacOS, Linux.

Установить библиотеки можно одной командой: pip install -r requirements.txt
